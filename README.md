# KI-Tarnkappe · Download

Ein Werkzeug von TOP effektiv: Kundendaten für ChatGPT, Claude, Copilot, Gemini und jede andere KI anonymisieren. Die echten Namen kommen danach von selbst zurück.

**Download für Windows:** [KI-Tarnkappe-Setup.exe](https://github.com/top-effektiv/ki-tarnkappe-updates/raw/main/KI-Tarnkappe-Setup.exe)

Beim ersten Start fragt das Programm nach Bestellnummer und Lizenzschlüssel. Beides steht in der Mail von Digistore nach dem Kauf.
Deine Kundendaten verlassen nie deinen Rechner.
